# situation_room — Pat's spec

Pat's English description: a non-coder saying what they want — sources,
processing, output — with no topology, agent count, or framework details.

feeds (BBC, NPR, Al Jazeera). For each article, classify the severity (low /
medium / high / critical), identify the geographic location, and write a short
briefing. Show me critical-severity briefings in my terminal; save all of them
to a JSONL file.
