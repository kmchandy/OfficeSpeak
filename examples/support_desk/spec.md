# support_desk — Pat's office description

I run a small online shop and want an office to handle customer emails.
Keep a file on each customer — their past orders, complaints, and
anything we promised them. When an email comes in, a helper pulls up that
customer's file and reads the email, a checker sees whether we've broken
any policy or promise for that customer, and a manager writes the reply
and notes what we did back in the file. Handle one email at a time so the
files stay consistent.
