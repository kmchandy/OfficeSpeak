# Gallery — find an office like the one you have in mind

These are worked examples of **offices** — small teams of software workers that watch
for information and react to it. If you're not sure how to describe the office you want,
skim these and find the one closest to your situation, then describe yours **in your own
words**, using it as a starting point. You don't have to match an example, and you don't
have to get it right the first time: the assistant builds a first draft and you fix it
together.

## Which one is like yours?

- **You have one stream of incoming information and just want to react to it** — watch
  it and speak up when something matters. → **room_monitor**
- **Your workers take turns, in rounds, repeating until someone decides to stop.** →
  **debate**
- **Several workers share one common file or ledger that they all read and update, and
  you want things handled one at a time so it stays consistent.** → **investment_club**
- **Your workers make proposals that need approval — checked against a shared limit or
  shared records — and each waits for the answer before acting.** → **trading_room**
- **None of these quite fit.** Describe your office anyway, in plain words. The assistant
  will build a first draft and you'll correct it.

## The examples

### room_monitor — *watch one thing, speak up when it's unusual*
A microphone listens to a room and puts an alert on the screen when it hears something
unusual — a loud noise, an odd silence, or someone talking. The simplest kind of office:
one source of information, a worker or two that watch it, and one place the alerts go.
*Good starting point if your office mostly watches a single feed and reports.*

### debate — *take turns in rounds until it's settled*
Three workers debate a question; each round every one gives an argument, and a moderator
reads them all and either calls for another round or, once it's settled, writes the final
answer. *Good starting point if your office repeats a cycle until some condition is met,
or several workers each weigh in each round.*

### investment_club — *a team deliberates, sharing one record, one item at a time*
Each period, two analysts recommend, a manager decides, and an accountant prices the
plan — all against one shared record of the club's holdings and history that they read
and update, handled one period at a time so the books stay consistent. *Good starting
point if several workers share a common book they both read and change.*

### trading_room — *propose, then get approval against something shared*
Two traders each propose trades; before any trade happens a ledger checks it against the
desk's positions, cash, and limits and approves or refuses. Each trader waits for the
answer before acting. *Good starting point if your workers make requests that must be
approved or checked against shared information.*

---

**A note on describing your office.** Talk about it the way you'd explain it to a
colleague: what information comes in, what you want to happen, who does what, and any
rules ("one at a time", "wait for the answer", "keep a running total"). You never need
to use technical words — the assistant turns your description into the office and shows
it back to you in plain English so you can correct it.
